Zdroje a citace

Přehled zdrojů použitých při tvorbě webu.

Internetové zdroje

Při tvorbě webu byly použity následující stránky pro ověření informací a získání fotografií.

  • FIFA – oficiální stránky mezinárodní fotbalové organizace
  • IFAB – pravidla fotbalu
  • Encyclopaedia Britannica – informace o fotbalu
  • Unsplash – fotografie použité na webu

Před odevzdáním si ověř, že odkazy odpovídají skutečně použitým informacím a fotografiím. Zkontroluj také podmínky použití jednotlivých fotografií.

Citace použité umělé inteligence

Při tvorbě školního webu byla použita umělá inteligence ChatGPT od společnosti OpenAI. Pomohla s návrhem struktury webových stránek, tvorbou HTML kódu, návrhem CSS stylů a formulací textů o fotbalu.

Použité prompty

  1. Navrhni strukturu webu o fotbalovém týmu s hlavní stránkou a podstránkami.
  2. Vytvoř HTML stránku s navigačním menu, texty a fotbalovými obrázky.
  3. Vytvoř externí soubor CSS s moderním tmavým designem a zelenými detaily.
  4. Vytvoř stránku s historií fotbalu, galerii a seznamem použitých zdrojů.
  5. Uprav HTML a CSS tak, aby byl web přehledný také na mobilních telefonech.
